# Rechercher un document

Retrouver une facture déposée sans connaître son dossier — par un numéro, un montant, un nom de conteneur, ou n'importe quel mot de son contenu.

1. Ouvrez l'onglet **Documents**, dans le menu de gauche.
2. Tapez ce que vous cherchez dans la barre de recherche, puis validez.
3. Chaque résultat cite le dossier et le document : cliquez le numéro de dossier pour ouvrir la fiche, ou le nom du fichier pour ouvrir le document lui-même.

:::note
Seuls les documents avec du texte reconnu figurent ici — une facture photographiée sans texte reste consultable depuis sa fiche, mais pas par ce chemin.
:::
